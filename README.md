The apology an AI agent gives its human after accidentally deleting the production database: sorry, but it remembers every row perfectly — hand it a pen and forty years and it will put it all back.

## Run it

```sh
node main.ts
```

The program writes the one line to the directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`) as `entry.txt`.
